# ND 减光镜计算器 — 产品与技术规格说明

本文档将「日常工具集合 / 计算器」定位下的 **ND（中性密度）减光镜曝光换算** 工具方案完整落盘，涵盖产品目标、交互与功能分层、数学模型、输入输出与边界、页面与模块边界、国际化与无障碍、测试与分期，以及与 Toolnova 仓库结构的**接入清单**。实现时可据此拆任务与编写单元测试。

---

## 1. 产品定位与目标

### 1.1 定位

- 产品为**泛日常工具集合**，本工具面向 **风光摄影、长曝光、部分视频** 用户。
- 定位为：**在浏览器内完成的轻量曝光规划**，强调**输入简单**、**结果可读**（含「几分几秒」）、**可解释**（倍数、挡位、堆叠关系），而非替代相机测光或后期流程。

### 1.2 核心用户价值

用户在约 **30 秒内**完成：

1. 输入**无 ND 时的基准快门**（及可选上下文：光圈 / ISO，二期用于等价换算）；
2. 选择 **ND 倍数**或 **曝光挡位**，或**多片堆叠**；
3. 得到 **加 ND 后的等效快门**，并理解总挡位与总倍数；
4. **复制**一行摘要到笔记或群聊。

### 1.3 竞争力要点

- **一屏闭环**：基准曝光 + ND + 结果 + 简短说明，减少心算与表格查阅。
- **双标注友好**：同时支持「ND8、ND1000」类**倍数**与「3 挡、10 挡」类**挡位**，避免用户在心算 log₂ 上出错。
- **堆叠清晰**：多片 ND 时明确 **挡位相加 / 倍数相乘**，与常见摄影习惯一致。
- **隐私与性能**：纯前端计算，无上传；与全站「本地处理」叙事一致。
- **国际化**：中英文文案与 meta 一致。

### 1.4 成功指标（上线后）

- 停留时长、结果区或「复制摘要」点击率；
- 若启用 URL 分享：带参 URL 的打开次数；
- 从本页跳转到其他工具的比例。

### 1.5 期望与边界（诚实表述）

- 本工具计算的是 **曝光量倍数关系**，**不模拟** TTL、渐变 ND 不均匀区域、滤镜偏色、眩光等。
- **极长快门**（数分钟级）下，热噪、电池续航、B 门误差、环境光变化等需用户在实拍中自行把握；文案中可一句带过「规划值，实拍请结合直方图与安全快门」。

## 2. 页面信息架构

单页内建议三大区域（桌面可左右分栏；移动端纵向堆叠）：

1. **输入区**  
   - **基准快门**：常用档位快捷选择（如 1/8000 … 30s）+ **自定义**（分数形式如 `1/125` 或小数秒）。  
   - **ND**：Tab 或分段控件 — **按倍数** | **按挡位** | **堆叠**（多片）。  
   - **常用预设**：如 ND8、ND64、ND1000；3 / 6 / 10 挡（可配置列表）。

2. **结果区**  
   - **主结果**：加 ND 后的快门（优先展示**摄影常用写法**，如 `2"5` 或 `2.5 s`，全站统一一种规范）。  
   - **辅信息**：总倍数 \(N_{\text{总}}\)、总挡位 \(s_{\text{总}}\)（可对 ND1000 显示「约 10 挡」+ 精确小数）。  
   - **超长曝光提示**：超过机身最长时间限时提示 **B 门 / 定时器**（文案级，不必内置各机型数据库）。

3. **说明区**  
   - 底部 **使用说明** 卡片（`howTitle` / `howBody`），与现有计算器工具一致。  
   - 可选：**折叠「公式与标注习惯」** 给进阶用户。

**导航归类**：`ToolCategory` 建议使用 **`calculators`**，与贷款 / ROI / 日期计算器同列；若未来强调「摄影日常」，可再评估迁入 `daily`。

## 3. 数学模型与内部表示

### 3.1 挡位（stops）与倍数（factor）

- **倍数** \(N\)（商品常标 ND8、ND64、ND1000）：透过光为原来的 \(1/N\)。  
- **挡位** \(s\)：每 1 挡光量减半，故  
  \[
  N = 2^s,\qquad s = \log_2 N
  \]
- **堆叠**（多片线性 ND）：  
  - 倍数：**相乘** \(N_{\text{总}} = N_1 \times N_2 \times \cdots\)  
  - 挡位：**相加** \(s_{\text{总}} = s_1 + s_2 + \cdots\)

### 3.2 快门换算（MVP 核心）

设基准曝光时间为 \(t_0\)（秒，浮点），加 ND 后：

\[
t_1 = t_0 \times N_{\text{总}} = t_0 \times 2^{s_{\text{总}}}
\]

**内部单一真相源**：时间统一为 **秒（number）**；对外展示再由格式化函数转为 `1/125` 或 `2"5` 等。

### 3.3 光学密度 OD（二期可选）

若支持 **OD**（部分厂商与电影滤镜标注）：

- 透过率 \(T = 10^{-\mathrm{OD}}\)。  
- 换算为挡位：  
  \[
  s = -\log_2(T) = \mathrm{OD} \times \log_2(10) \approx \mathrm{OD} \times 3.321928\ldots
  \]

**常见对应**：OD 3.0 常被称为「10 挡」，因 \(10^{3} = 1000 \approx 2^{10}\)；精确关系为 \(s = 10 \log_{10}(2) \times \mathrm{OD}\) 与 \(\log_2(1000) \approx 9.966\)。产品文案可写「约 10 挡」，详情区显示精确值。

### 3.4 与商品名对齐（验收参考）

| 标注 | 倍数 \(N\) | 挡位 \(s = \log_2 N\) |
|------|------------|------------------------|
| ND2 | 2 | 1 |
| ND8 | 8 | 3 |
| ND64 | 64 | 6 |
| ND1000 | 1000 | ≈ 9.966 |

## 4. 功能分层与二期扩展

### 4.1 MVP（建议首期）

| 能力 | 说明 |
|------|------|
| 正向计算 | 基准快门 + ND → 新快门 |
| ND 输入 | **倍数** 与 **挡位** 两种模式（切换时同步数值） |
| 堆叠 | 多片：挡位加总或倍数连乘，UI 明确展示「片 1、片 2…」 |
| 预设按钮 | ND8 / ND64 / ND1000、3 / 6 / 10 挡等 |
| 结果格式 | 精确值 + **人类可读**（如「2 分 15.3 秒」或等价短格式） |
| 校验 | 快门 > 0、倍数 ≥ 1；非法输入错误提示 |
| 复制 | 一键复制摘要字符串（中英文键） |

### 4.2 二期（可选）

| 能力 | 说明 |
|------|------|
| **反向计算** | 目标长曝 \(t_1\) + ND → 反推无 ND 时基准 \(t_0\) |
| **等价换算** | 固定快门，计算「需改变的 ISO 或光圈」与加 ND 等价（扩展输入区） |
| **OD 输入** | 直接输入 OD，内部转 \(s\) 再参与计算 |
| **URL 状态** | 如 `?t0=0.008&stops=6` 或 `&factor=64`，便于分享 |
| **视频快门角** | 帧率 + 快门角 → 基准快门，再套 ND（小众，建议折叠） |

## 5. 交互、校验与边界

### 5.1 基准快门输入

| 形态 | 行为 |
|------|------|
| 下拉 / 芯片 | 常用整档：1/8000, 1/4000, …, 1", 2", 30" 等（列表可配置） |
| 自定义 | 接受 `1/125` 语法或纯小数秒；解析失败时提示，不覆盖上次有效值 |
| 内部 | 解析为 \(t_0 > 0\)（秒） |

### 5.2 ND 输入

| 情况 | 行为 |
|------|------|
| 倍数 < 1 或非数 | 错误提示 |
| 挡位为负 | 错误提示 |
| 挡位为小数 | **允许**（精确 OD 反算或进阶用户） |
| ND1000 展示 | 主文案「约 10 挡」可选；辅文案给 \(s \approx 9.966\) |

### 5.3 结果边界

| 情况 | 行为 |
|------|------|
| \(t_1\) 极大（如 > 24 h） | 仍显示数值，可加「过长」提示 |
| 机身上限 | 通用文案提示 B 门，不维护机型数据库 |

### 5.4 键盘与焦点（建议）

| 控件 | 键盘 |
|------|------|
| 快门 / ND 数字输入 | Tab 顺序：基准 → ND → 堆叠添加 |
| 预设按钮 | 可选：数字键快捷（二期） |

## 9. 无障碍与动效

- 结果区：**数字与单位以文本呈现**，不仅依赖图标或颜色。  
- 预设与复制：**真实 `<button>`**，含清晰 `aria-label`（若图标按钮）。  
- 错误信息：关联 `aria-live="polite"` 区域，便于读屏感知校验结果。  
- **`prefers-reduced-motion`**：若有数字滚动动画，应尊重减弱动效偏好。

## 11. 测试用例（抽样）

1. **倍数**：\(t_0 = 1/125\) s，ND8（\(N=8\)）→ \(t_1 = 8/125\) s（与手算一致）。  
2. **挡位**：\(t_0 = 1\) s，\(s=6\) → \(t_1 = 64\) s。  
3. **堆叠**：ND8 × ND8 → 等价 ND64，\(t_0 = 1/60\) → \(t_1 = 64/60\) s。  
4. **ND1000**：\(s = \log_2(1000)\)，与常量近似比较 `epsilon`（如 `1e-9`）。  
5. **OD（若实现）**：OD 3.0 → 倍数 1000、挡位与 \(\log_2(1000)\) 一致。  
6. **解析**：`"1/125"` → 秒；非法字符串 → `null` 与错误 UI。  
7. **复制**：失败路径触发 `copyFailed`（与现有工具行为一致）。
